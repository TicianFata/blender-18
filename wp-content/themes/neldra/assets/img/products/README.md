# Product images — upload here

Drop the **N01 sofa** photos into this folder. Once they're here, tell the
filenames to Kiro and they get wired into the homepage hero, the shop grid and
the product gallery (and the standalone files get rebuilt).

## Suggested filenames (so roles are clear)
Rename your photos to any of these that apply — order = gallery order:

| Suggested name | Use |
|----------------|-----|
| `n01-front.jpg`     | Product hero / shop-card image (the clean front or 3/4 view) |
| `n01-angle.jpg`     | Alternate 3/4 angle |
| `n01-side.jpg`      | Side profile |
| `n01-back.jpg`      | Back view |
| `n01-detail-1.jpg`  | Close-up (edge / slab detail) |
| `n01-detail-2.jpg`  | Close-up (cushion / material) |

Anything not matching is fine too — just list what you upload.

## Format tips (for the "floats on white" look)
- **JPG or PNG**, shot on **pure/near-white** so the edge dissolves into the page.
- ~**2000 px** on the long side, **< 500 KB** each if possible (keeps the site fast).
- Consistent framing/scale across shots.

## How to upload on GitHub
Repo → open this folder → **Add file ▸ Upload files** → drag your photos in →
**Commit changes**. (Or drag them onto the folder page.)
